# 让 AI Agent 直接操作真实的剪辑时间线

WeftCut 是一款免费开源的视频剪辑软件，内置 MCP 服务。接入 Claude、Cursor、Codex 或你自己写的客户端之后，agent 拿到的是和你完全一样的剪辑能力——切分、修剪、关键帧、特效、字幕、标记、音频——并且实时落在你眼前的时间线上。

大多数剪辑软件把 AI 当成一个附加功能：一个按钮，做厂商替你选定的那一件事。WeftCut 的做法是把编辑器本身开放成工具接口，同时一个模型都不内置。智能来自你接入的那个 agent。

## Agent 具体能做什么

MCP 工具覆盖时间线操作、动效、字幕、音频、分析、Motif 创作与工程历史。它们直接修改你在应用里看到的工程。导出由应用中的导出界面启动。

- **时间线**：在 A/B 卷时间线上放置、移动、修剪、切分片段，按 SMPTE 时间码对齐到帧。`auto_split_by_shot` 在每个镜头切换处下刀，`detect_pauses` 找出停顿，`remove_pauses` 将它们剪掉并闭合空隙，整次操作可一步撤销。
- **动效**：带贝塞尔缓动的关键帧、切线控制、运动路径与外推。
- **画面**：分层特效链，含色度键抠像。
- **文字**：带样式的标题层；`apply_subtitles` 可把 SRT、VTT、ASS 导入为可编辑的字幕层，并支持一步撤销地重排全片字幕样式。
- **Motif**：参数化的动态图形，包括标题、2D 绘制与 3D 场景，预览与导出像素一致。详见 [Motif 说明](/zh/motifs/)。
- **音频**：按角色调整增益与静音／独奏、提取原始音频、转写语音与云端配音。
- **结构**：嵌套合成、关联音视频、标记与检查点。
- **安全网**：`dry_run` 可以在真正改动之前先校验一次；agent 的每一步都能像你自己的操作一样撤销与重做。

## 一分钟接入

打开「设置 → Agent」，复制连接提示或客户端配置。推荐使用随应用提供的 `weftcut-mcp` 桥接程序，应用重启、端口变化或 token 轮换后配置仍然有效，也无需另装 Node。

无法启动 stdio 服务的客户端仍可使用 HTTP 直连。从应用复制当前的地址与 token，不要写死端口。应用还随附指导剪辑和 Motif 创作的 agent Skill。

详细配置见[当前连接文档](https://github.com/WeftCut/WeftCut/blob/main/docs/mcp.md)。

## 什么会留在本机

剪辑与导出在本地运行。应用内的 MCP 服务只绑定回环地址（`127.0.0.1`），并通过 bearer token 鉴权和 DNS 重绑定防护保护。

你接入的 agent 遵循它自己的服务商数据政策。可选的云端转写或视觉分析会将所需音频或画面发往你配置的服务商；选择本地引擎可让这些分析也留在本机。

## 主动权始终在你手里

Agent 的改动不是一个黑箱，也不是甩给你一个成片。

- `begin_agent_session` 会把界面切换到简洁的 agent 模式，让"现在不是你在剪"这件事一目了然。
- 每一次操作都按顺序落进实时变更记录里。
- 改动会归到一个检查点下，整轮操作可以作为一个整体撤销；你也可以中途接手，和 agent 并行地继续剪。

## 让它先看清楚再下刀

镜头检测、停顿检测与画面比对在本地运行。转写可以使用云端服务，或下载的 whisper.cpp、FunASR 等本地引擎。画面描述支持本地视觉模型或你配置的云端服务。Agent 也可提取片段原始音频，使用自己的语音处理流程。

这些工具都是可选项。安装包不附带模型权重，本地引擎与模型在你选择使用时下载。

## 不接 agent 也是一台完整的剪辑软件

如果你从不接入 agent，功能也并不残缺。WeftCut 本身就是完整的桌面非线性剪辑软件：带缩略帧与波形的 A/B 卷时间线、时间线内的贝塞尔曲线编辑器、特效链、带实时吸管的色度键、字幕、Motif、按角色分组的音频混音，以及 H.264、HEVC、10-bit AV1、ProRes、DNxHR 导出。

## 常见问题

### 支持哪些 MCP 客户端？

都支持。最常见的是 Claude Desktop、Cursor 和 Codex，但服务端实现的是标准 MCP，支持随应用提供的 stdio 桥接程序或 HTTP 直连，你自己写的客户端也能接入。

### WeftCut 自带 AI 模型吗？

安装包不附带模型权重。剪辑智能来自你接入的 agent；可选的语音与视觉工具可使用下载的本地引擎，或你配置的云端服务。

### Agent 会不会把我的工程搞坏？

它会改动工程——这本来就是目的——但不会不可挽回。操作可以先用 `dry_run` 校验，每一步都实时进入变更记录，改动归入检查点，撤销对 agent 的操作和对你自己的操作完全一致。

### 这个 MCP 服务会暴露在局域网里吗？

不会。它只绑定回环地址，需要 bearer token，并带有 DNS 重绑定防护。只有你本机上的程序能访问它。

### 真的免费吗？

是。MIT 许可开源，支持 macOS、Windows 与 Linux；随附的 FFmpeg 遵循其自身的 LGPL/GPL 条款。也可以看看[这里说的"AI 剪辑"到底指什么](/zh/ai-video-editor/)。
