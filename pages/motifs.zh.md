# 代码即动效

Motif 是 WeftCut 里的一种动态叠加层——字幕条、倒计时、带动效的标题——它以参数化的代码形式存在，而不是一段压平的素材。你的 agent 本来就擅长写代码，Motif 就是这件事变成动效的地方。

## Motif 到底是什么

它不是拖进时间线的视频文件，也不是只有三个滑块的预设。Motif 是一个小巧的参数化网页叠加层：它有自己的控件，像其他图层一样在时间线上播放，放进去之后参数仍然可以继续改。

最关键的一点是，它在预览和导出里的渲染结果像素一致。你拖动播放头看到的画面，就是最后落进文件里的画面——没有另一条渲染路径，也没有最后一刻的意外。

## 先从现成的开始

WeftCut 内置了一批起点，选择器里带实时预览：

- **字幕条**：进出场带动画的姓名与头衔条
- **倒计时**：按你设定的节奏走的计时器
- **文字特效**：带动效的标题与说明文字

选一个，调一下控件，它就在时间线上了。这一步完全不需要 agent。

## 也可以让 agent 直接写一个

有意思的地方在这里：大语言模型真正擅长的事情——写小段、精确、带参数的代码——恰好就是 Motif 的形态。

1. **描述**：告诉 agent 你想要什么，标题、字幕条、说明框，甚至一个还不存在的设计都行。
2. **预览**：agent 把想法变成一个 Motif，马上可以在时间线上播放。
3. **打磨**：在实际画面里继续调——改参数，或者再让它改一版——直到对为止。

你说「给这场戏加一个标题、一个字幕条和一个倒计时」，拿到的是三个真实可编辑的图层，而不是三条建议。

## 是参数，不是副本

因为 Motif 是参数化的，做好的样式天然可复用。改掉文字，它就是另一张卡片，而不是另一个素材。下一个项目继续用，它仍然是一份需要维护的东西，而不是一个塞满近似导出文件的文件夹。

这也让它很适合成批交给 agent：重排一整组叠加层的样式或内容，是一次参数改动，不是重画一遍。

## 它在整个编辑器里的位置

Motif 只是众多图层类型中的一种。它和你的片段、字幕、特效待在同一条时间线上，同样支持关键帧，也走同一条导出路径，输出到 H.264、HEVC、10-bit AV1、ProRes 或 DNxHR。

通过 MCP 接入的 agent 可以像执行其他剪辑操作一样创建、放置和调整 Motif——接入方式见 [MCP 说明](/zh/mcp/)。

## 常见问题

### 不用 AI agent 能用 Motif 吗？

能。内置目录本身就能用，选择器里有常规控件。agent 是为了做目录里没有的东西。

### 导出后的效果会和预览不一样吗？

不会。Motif 在预览和导出中渲染结果一致，你拖动播放头看到的那一版，就是落进文件里的那一版。

### 能做目录里没有的 Motif 吗？

能。「描述—预览—打磨」这个循环就是为此存在的：agent 按你的描述写一个新的，而不是从现有选项里挑一个最接近的。

### Motif 能跨项目复用吗？

可以。Motif 是参数化的，同一个叠加层可以带到下一个项目，你改的是它的参数值，而不是重做一遍。

### 这个功能收费吗？

不收费。Motif 是 WeftCut 的一部分，而 WeftCut 基于 MIT 许可免费开源，支持 macOS、Windows 与 Linux。也可以看看[整体介绍](/zh/ai-video-editor/)。
