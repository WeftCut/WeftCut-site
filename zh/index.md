## 原生设计，*面向智能体。*

通过标准 MCP，让你的 agent 直接参与时间线上的剪辑，每一项真实改动都即时可见。

- 接入

  设置 → Agent，复制、粘贴，一分钟接入 Claude、Cursor 或任意 MCP 客户端。随附的 Skill 让 agent 了解 WeftCut 的完整能力。剪辑与导出在本机完成。
- 工具

  剪辑所需的工具一应俱全：修剪、切分、转场、关键帧、特效、字幕、标记与撤销。
- 掌控

  改动实时落在时间线上。通过检查点与变更记录审阅，或随时撤销并重新接手。
- 洞察

  让 agent 先看、先听，再开始剪辑：识别镜头与停顿、转写语音、描述画面。可选择本地引擎，或配置云端服务。

*直接告诉 agent 说句话，剪辑就落到时间线*

- 「删掉这段采访里的无声部分，再把停顿收紧一点。」
- 「在每个镜头切换处把这条素材切开，标上场次。」
- 「把所有字幕的样式重做一遍——字再大一点，加柔和阴影。」

## 常见问题

- ### WeftCut 免费吗？

  是的。WeftCut 免费使用，并基于 MIT 许可证开源；随附的 FFmpeg 遵循其自身的 LGPL/GPL 许可条款。
- ### 支持接入哪些 agent？

  任何支持 MCP 的客户端都可以，包括 Claude Desktop、Cursor、Codex，也包括你自己开发的客户端。在「设置 → Agent」中复制配置并粘贴到客户端，agent 就能与你协同剪辑。WeftCut 不内置 AI 模型，智能能力来自你接入的 agent。
- ### 不接 agent 也能用吗？

  能。WeftCut 本身就是一款完整的剪辑软件，提供时间线、关键帧、特效、字幕、Motif、音频混音，并支持 10 位 AV1、ProRes 等格式导出。
- ### AI 在哪里运行？

  剪辑智能来自你接入的 agent。WeftCut 不附带模型权重。可选的语音与视觉工具使用你下载的本地引擎，或你配置的云端服务。
- ### 支持哪些平台？

  支持 macOS、Windows 和 Linux，所有平台均提供一致的功能。现成的安装包覆盖 Windows x64、Apple Silicon Mac 与 x86\_64 Linux；其他平台可自行从源码构建。
