WeftCut 说的「AI 剪辑」到底指什么

WeftCut 是一款免费开源的 AI 视频剪辑软件，支持 macOS、Windows 与 Linux。这个说法值得先讲清楚，因为它和大多数"AI 剪辑"通常指的东西不太一样。

先说结论：它一个模型都不内置

市面上多数号称 AI 剪辑的工具，跑的是厂商选定的模型、在厂商的服务器上、处理你上传上去的素材。WeftCut 一样都不做：不内置模型，没有推理接口，没有账号体系，也没有需要上传的地方。

它做的是另一件事——把整个编辑器开放出来。通过标准的 MCP 协议，在你自己的电脑上，把剪辑能力交给你本来就在用的 AI agent：Claude、Cursor、Codex，或者你自己写的那个。智能由 agent 提供，时间线由 WeftCut 提供，agent 的改动实时落在时间线上，你看得见，也随时能撤销。具体接入方式见 MCP 说明。

所以：AI 是真的，剪辑也是真的，只是这个 AI 不归我们，也不在你看不见的地方运行。

哪一行最重要，取决于你是谁。对不少人来说是第一行。

Agent 在这里具体做什么

说人话，出真改动：

  • 「把这段采访里的静音都剪掉，把停顿收紧一点。」
  • 「在每个镜头切换处切开，并标注场次。」
  • 「把所有字幕重新排一下——字号大一点，加一点柔和阴影。」

这些都会变成普通的时间线操作，你可以检查、微调，也可以撤销。转写、镜头检测、静音检测、画面描述等可选分析同样在本机运行，所以 agent 可以"先看清楚再下刀"，而素材哪儿也没去。

把 AI 关掉，它依然是一台正经剪辑软件

一个 agent 都不接，你手上仍然是完整的非线性剪辑软件：

  • 带缩略帧与音频波形的 A/B 卷时间线，按 SMPTE 时间码对齐到帧
  • 时间线内直接编辑贝塞尔曲线的关键帧动画
  • 分层特效链，含带实时吸管的色度键抠像
  • 标题与字幕，支持把 SRT、VTT、ASS 导入为可编辑图层
  • Motif：可复用的动态叠加层，比如字幕条与倒计时
  • 按角色分组的音频混音，分别处理对白、音乐与音效
  • Ctrl-K 面板，一次搜索命令、素材、片段、字幕与标记，支持拼音

平台与导出

一个桌面应用，覆盖 macOS、Windows 与 Linux，三个平台功能一致。导出支持 H.264、HEVC、最高 10-bit 的 AV1、ProRes 与 DNxHR，可用硬件或软件编码器，整条时间线或选定区间都行。

Linux 拿到的是和其他平台一样的版本——这在同类剪辑软件里并不常见。

常见问题

WeftCut 收费吗？

不收费。基于 MIT 许可开源，没有付费档位，也没有按席位计费；随附的 FFmpeg 遵循其自身的 LGPL/GPL 条款。

导出会带水印吗？

不会。任何分辨率、任何格式的导出都没有水印。

我的素材会被上传吗？

不会。剪辑和导出都在本地完成，可选的分析功能同样在本地运行。WeftCut 没有账号系统，也没有可供上传的服务器。

断网能用吗？

编辑器完全可以。唯一需要联网的是你接入的 AI agent，因为那是一个独立的程序，连的是它自己的服务。

支持 Linux 吗？

支持。macOS、Windows 与 Linux 使用同一个桌面应用，功能一致，包括 10-bit AV1 与 ProRes 导出。

它用的是哪家的 AI 模型？

没有自己的模型。WeftCut 不内置任何模型，智能来自你接入的 agent；可选的本地分析使用 Whisper 这类在设备上运行的工具。
